# XS™ Grass-Fed Whey vs. Jay Robb Grass-Fed Whey Isolate

| Feature | **Amway XS™** | **Jay Robb** |
|---|---|---|
| **Price per serving** | ~$3.05 | ~$1.75–$2.17 ✅ |
| **Protein per serving** | **30g** ✅ | 25g |
| **BCAAs** | **6.9g** ✅ | Not listed |
| **Calories / Fat** | 140 cal / 1.5g fat | 110 cal / 0g fat ✅ |
| **Sweetener** | Stevia only | Stevia only |
| **Additives** | Sunflower Lecithin only ✅ | Xanthan Gum + Lecithin |
| **rBGH-free** | ✅ Consistent | ⚠️ Not always guaranteed |
| **Gluten / Soy / Lactose free** | ✅ | ✅ (processed with soy/wheat) |
| **Third-party certified** | **NSF Contents Certified** ✅ | None |
| **Availability** | ✅ Consistent | ⚠️ Frequent stock-outs |

---

## Why XS™ Wins

- **Organic** - 100% Organic whereas Jay Robb's is not
- **20% more protein** — 30g vs. 25g, plus 6.9g BCAAs listed on label
- **NSF certified** — independent lab verifies the label; Jay Robb has no equivalent
- **Truly grass-fed, no asterisks** — Jay Robb admits it may substitute non-rBGH-free whey when supply runs short
- **Cleaner formula** — no xanthan gum, which can cause digestive discomfort

## Where Jay Robb Has the Edge

- **Lower cost per serving** (~$1.75–$2.17 vs. ~$3.05)
- **Fewer calories and zero fat** — better protein-per-calorie ratio for strict cuts
- **Heritage brand** — claims to be the first rBGH-free whey protein (since 1990)

---

**Bottom line:** Both use whey isolate and stevia. XS pulls ahead on protein content, being organic, third-party quality verification, sourcing consistency, and availability — Jay Robb's main advantage is price.
